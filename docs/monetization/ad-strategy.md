# DevHub 收费与广告策略（运营执行稿）

更新时间：2026-05-26  
适用版本：`config/pricing.json@2026-05-26`、`config/entitlements.json@2026-05-26`

## 1. 收益结构目标

- 主收入：订阅/授权，目标占比 `70%~90%`。
- 辅收入：广告/联盟，目标占比 `10%~30%`。
- 原则：广告不能影响安装成功率和产品信任度。

## 2. 广告位规范（仅 Free）

- 广告位A：主界面右侧底部，`mainSidebarSponsor`，最多1条。
- 广告位B：安装完成页底部，`postInstallRecommend`，最多2条。
- 必须标注“赞助/广告”，不允许伪装系统通知。
- 禁止：弹窗广告、开屏广告、安装过程中插屏。
- 支持“本次会话关闭推荐”，下次会话可恢复。

## 3. 套餐与权益

- 免费版 `Free`：基础安装能力 + 限定广告位。
- 个人版 `Pro`：`¥199/年`，3台设备，去广告，高级批量能力。
- 维修版 `Tech`：`¥899/年`，按月滚动200台额度，去广告，离线缓存与模板。
- 企业版 `Business`：`¥39/设备/年`，最低 `¥6000/年`，高级审计与优先支持。

详细字段以配置为准：
- `config/pricing.json`
- `config/entitlements.json`

## 4. A/B 测试执行（14天）

- A组：仅展示完成页广告位（B位）。
- B组：展示右侧位 + 完成页位（A+B位）。

观察指标：
- 安装完成率（核心门槛）。
- 7日回访率。
- 广告点击率（CTR）。
- 付费转化率（Free -> Pro/Tech/Business）。

回滚阈值：
- 如果安装完成率下降超过 `2%`，立即回滚到 A 组策略。

## 5. 合规边界

- 推荐内容必须来自官方源或明确可验证来源。
- 不得推荐绕过许可、破解、灰产下载。
- 推荐文案不得暗示与第三方厂商存在官方背书关系。

## 6. 落地顺序建议

1. 先上线 `pricing/entitlements` 配置与开关读取，不改安装主流程。
2. 再接入 UI 广告位组件（仅 Free 生效）。
3. 最后接入许可证校验与设备额度统计。
