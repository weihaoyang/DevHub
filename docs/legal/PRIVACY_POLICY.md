# DevHub Privacy Policy

Last Updated: 2026-02-17

## 1. Overview

This policy explains what data DevHub handles, where it is stored, and how users can control it.
DevHub is designed as a local-first desktop tool.

## 2. Data Processed by DevHub

DevHub may process the following local data on your device:

1. App settings (language, proxy settings, compliance acceptance state).
2. Installation task metadata (selected package IDs, status events, exit codes).
3. Local logs for troubleshooting.

DevHub does not intentionally read your personal document contents as product input.

## 3. Default Network Behavior

By default, DevHub does not upload personal data, file contents, or telemetry to a DevHub server.
Network requests are primarily made to package sources and vendor endpoints required for installation.

## 4. External Links

When you open external links (such as vendor pages or donation pages), your system browser handles those sessions.
Those sites are governed by their own privacy policies and terms.

## 5. Storage and Retention

Settings and logs are stored locally on your device.
You are responsible for log retention and cleanup in your environment.
Recommended baseline: regularly remove old logs that are no longer needed.

## 6. Security Notes

No software can guarantee absolute security.
You should use endpoint protection, system updates, least-privilege practices, and encrypted storage where appropriate.

## 7. Enterprise and Compliance Use

If your organization has internal requirements (for example data residency, log retention periods, or audit controls), configure and use DevHub accordingly before rollout.

## 8. Minors

DevHub is intended for technical system setup scenarios and is not targeted at minors.
If local law requires guardian consent, obtain it before use.

## 9. Policy Updates

If DevHub introduces cloud collection or analytics in the future, this policy must be updated before such collection is enabled.
